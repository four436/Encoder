# Encoder
Aceste este unul din primele proiecte făcute în Java.  
## Descrierea programului
Este un program simplu care rulează în terminal (nu are interfață grafică), care la rularea acestuia te întreabă dacă dorești să criptezi un fișier text sau să îl decriptezi. Criptara se face prin citirea fiecărui caracter din fișier și scrierea codului corespunzător caracterului în fișierul unde dorești să fie scris mesajul criptat. Pentru selectarea fișierelor se deschide o interfață de "browse" pentru fișiere. **Doar fișierele .txt pot fi criptate**  
## Dependințe
Librăriile utilizate:  
  * import textio.TextIO
    - pentru a putea selecta și citi fișierele
Limbajul necesar pentru realizarea acestuia: **Java** (minim versiunea 8.0)
